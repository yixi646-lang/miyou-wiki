Wiki 1.2.0 版本更新详情
发布批次：R000006
适用起点：Wiki 1.1.1 / R000005
发布日期：2026-10-15

本次为功能版本发布，汇总1.1.1正式发布以来整个公共发布范围的最终变化。文件、图片、来源及版本资料通过快照比较收集，正式百科数据库另作一致性公共导出；不按某次对话或文件日期筛选。
本次仅生成1.1.1至1.2.0更新包。全部文件与公共条目差异见“更新文件清单.txt”，实际数量见“更新说明.txt”；简短使用教程见“Wiki使用说明.txt”。

一、GO求解器与圣遗物配装计算
1. 使用现有固定提交的GO求解器接入库存配装搜索，适配已规定的满级、套装、主词条、借用、双面板和全队唯一分配规则，沿用当前武器。
2. 每名队员可选择一个或多个计算部位，未选部位固定当前装备；筛选约束搜索部位，套装与面板要求约束完整配装。全队分配不借走其他队员的固定圣遗物。
3. 结果支持指标优先和少换件。在可调指标差距内按换件数、借用数排列，保留候选编号及操作关联；仅重排已保留候选，不宣称全库存最优或最少换件。
4. 计算角色旁提供当前配装详情。非战斗面板、队伍战斗面板目标并排切换，只有选择具体属性才写入目标。
5. 新建属性范围默认仅列生命值；旧七项空默认行收紧，已有上下限与手动新增条件保留。条件控件、进度和结果排序紧凑对齐，窄屏自然换行。

二、理论配装与词条自动分配
1. 队伍配装加入理论词条分配，从零配置或重分配当前五件；固定次数可编辑，参与副属性、新增次数上下限及战斗/非战斗面板范围均参与GO求解和具体五件复核，不能默默放宽。
2. 结果分别展示固定、新增、合计次数及实际满足的面板值，通过次数与档位合法性检查，沿用已有自定义圣遗物分类，不新增独立仓库。
3. 增加有效副词条加权评分、有效副词条总量与双暴目标，复用当前角色权重和星级换算口径。
4. 理论结果可试算、保存方案或存入自定义分类，不自动改写实际GOOD装备。用途、快速上手、预算和固定/新增范围说明在窗口内默认折叠，保留展开状态。

三、强化、重塑和祝圣定义潜力
1. 圣遗物页通过“库存 / 强化潜力”进入，选择队伍、队员及计算目标；复用库存套装、主副词条、星级、装备与锁定状态、来源和数值筛选，按概率或平均提升排列候选。
2. 强化、重塑、祝圣定义分别展示概率与具体示例，可自设比较阈值，区分严格超过与达到；条件均值按超过阈值的目标结果计算。借用装备时计入原装备角色卸下该件的变化。
3. 重塑按最终数值推导全部合法初始档位组合，区分估计与真实记录；默认按目标推荐已有副属性，也可手动设置档位及次数。0级三词条正确处理已知或随机第四条，排除零概率分支。
4. 具体结果先去重再展示最多九种合法示例，保留已知初始档位与总次数，不将示例称为全部结果或精确上限，不携带原件的管理标记。
5. 取消可续算未完成候选，失败项可重试；更改设置取消旧任务，库存变化后校验原件身份，防止过期结果覆盖或套用到其他装备。
6. 复算只读取目标数值并保留全队依赖，使用装备副本、合并进度回传，减少重复库存复制；详细概率仍是估计，不是游戏结果保证。

四、队伍动作、结果与装备操作
1. 固定动作组合支持独立命中方式、附魔、反应和增益，以及配置导入导出；固定动作合计仍不是完整循环DPS，不模拟完整附着与能量时序。
2. 强化天赋、固有天赋、元素投射的最终伤害/治疗纳入队伍结果；按GO公式类型区分护盾、伤害增加量和最终结果，保留真实机制开关。
3. 机制页展示自动武器效果当前数值，不添加虚构触发开关。计算核心继续采用项目记录的原神7.1开发版固定提交，不把百科资料范围当作计算机制全部覆盖。
4. 从库存替换圣遗物显示主副词条数值与当前装备角色，套装选择复用搜索及大版本浮层；子浮层关闭后保留父浮层筛选、焦点和滚动。
5. 恢复原有装备、移除当前装备使用独立按钮；锁定时可恢复、不可移除，保留原有配装供后续恢复。五件分析旁可仅恢复圣遗物，不影响武器。

五、账号、旅行者与操作体验
1. 旅行者七元素可切换并建立独立自定义元素方案；天赋、命座与评价目标分别保存，共用等级和突破仍受原有账号锁定保护，不把其他元素天赋复制为实测值。
2. 导入与备份提供当前账号自定义角色、武器、圣遗物转为默认资料，须解锁并由服务端校验版本；保留当前可见配装、数值、目标、工作区和原始导入快照，不覆盖隐藏的历史自定义版本。
3. 养成与评估改用Wiki外层滚动，移除固定容器及栏目滚动位置恢复，角色列表保留独立筛选滚动。
4. 标题旁可统一隐藏说明性文字并记住偏好，保留数值、进度、错误、确认与实际计算依据；理论快速上手及评价权重教程继续独立展开/折叠。
5. 打开队伍、账号、通用方案、圣遗物方案和百科条目名称编辑时聚焦文字末尾；普通重绘、搜索与已有选区保留。

六、搜索与材料获取资料
1. 顶栏“搜索”默认当前游戏，可选全部游戏，覆盖条目摘要、版本内容与立绘形态；结果按资料类别和游戏分组，复用原卡片、折叠、列数和立绘切换。
2. 支持相关度、名称、登场时间、稀有度及方向排序，未知值置后；排序不重新取资料，保留中文输入法及本页筛选，图片按可见卡片延迟加载。
3. 材料详情按已有获取文字分类，提取已录入地点、开放日、等级条件及产出配方；原神秘境入口、地区和难度按原材料固定来源提交及奖励关联补充，保留来源与压缩快照，不猜掉率、费用或缺失条件。
4. 三个游戏角色列表卡片取消重复星星/S、A标记和稀有度文字，保留稀有度背景色、元素图标及角色资料。

七、中文扫描器
扫描成功后不再自动弹出GO导入询问，GOOD仍自动导出，完成状态、错误提示和手动导出入口保留。识别采用当前已回退保留的ui.5原流程，未采用已撤回的姓名裁切、副词条备用识别或精炼OCR修复；中文界面和资料更新功能保留。
扫描仍需英文游戏画面、合适比例、关闭HDR并核对键位，先核对GOOD再导入；本次发布不执行真实游戏扫描。

八、安装与资料保留
关闭目标Wiki所有页面并等待约15秒，同时关闭扫描器。完整解压更新包到独立目录，双击“安装更新.vbs”，选择原1.1.1 / R000005目录，核对后开始，以向导明确显示“更新完成”为准。不要手动覆盖payload、SQLite或其他起点目录。
个人收藏、材料库存、旧计划、评估账号、实际和自定义装备、队伍与个人扫描不参与打包覆盖；百科公共条目三方合并，冲突保留本地值并记录。通用攻略及评价默认方案属于公共资料，自行修改过时先导出统一备份。
1.2.0按feature功能版本登记，维护者保留1.1.1发布快照引用作为本机功能回退点；分享版不加入软件版本回退或整份历史备份。本次只做发布覆盖核对与必要隔离安装确认，不检查本机回退，不开展浏览器回归或真实游戏扫描。
