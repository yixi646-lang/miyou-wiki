Wiki 1.1.1 版本更新详情
发布批次：R000005
适用起点：Wiki 1.1.0 / R000004
发布日期：2026-10-13

本修订版汇总1.1.0正式发布后至本次快照的全部公共范围变化，不只收集最后一轮对话或按修改时间筛选。新增文件、文件修改和删除、公共百科条目及相关图片、来源、版本档案均由发布快照比较纳入；个人账号与扫描记录不参与发布。
完整文件与条目清单见“更新文件清单.txt”，实际数量见“更新说明.txt”。本次仅生成1.1.0至1.1.1更新包。

一、多实例启动与机制文字修复
1. 每份Wiki按自身目录和资料库识别服务、保存本地端口；重复启动只复用当前目录实例，其他目录或程序占用端口时自动另选端口。
2. 复制目录中的旧实例配置不作为新目录身份，保留原启动入口。移动、复制后从该目录“启动百科.vbs”进入，不依赖原固定端口。
3. 共用机制说明解析展开本地中文词典的角色名引用，修正魔女课业等说明中的嵌套翻译和旧模板占位符；无法解析的引用保留原文，适配源码与计算核心同步更新。

二、圣遗物配装计算调整
1. 直接选择账号已保存队伍，取消前置角色选择；另提供可搜索、按名称/星级/元素筛选的单人角色入口。
2. 计算范围可选任意队员或全队，与“角色名＋指标”计算目标独立。单队员的搜索、结果和分析跟随实际所选成员；单成员队伍按单人范围兼容旧设置。
3. 队伍、范围、目标同行紧凑排列，窄窗口自动换行；浅金色说明分别解释三者用途，移除重复标题与说明。
4. 单人、全队及套装补充搜索仅纳入五星+20；仅当套装最高四星时纳入该套装的四星+16。低星、其他四星及未满级装备不作候选，库存原件继续保留，当前配装仍作比较基准。
5. 继续只搜索圣遗物，固定沿用当前武器；保存队伍条件、每名队员筛选、对应范围结果及实际装备权限保持原有规则。候选搜索仍受试算上限限制，不保证全库存最优。

三、原神养成与评估界面重组
1. 标题、账号选择与管理按钮同行收窄；角色列表简化为星级配色头像与名称，保留添加、移除、排序、独立滚动和栏目位置记忆。
2. 评价的四项统计紧凑展示，内容通过概览、圣遗物、培养建议、培养攻略、提升收益标签查看；保留完整原有内容，评价设置中的说明默认折叠。
3. 队伍成员与管理按钮同行，内容按战斗条件、配装与对比、战斗面板、队伍伤害等入口查看；条件可按分类和编辑成员切换，战斗面板及固定动作直接展示。
4. 配装对比可统一展开/折叠全体成员配装，伤害结果按成员统一展开/折叠技能分类；重绘保留状态。机制恢复默认只作用于当前编辑成员。
5. 圣遗物、武器改为模块一级栏目，与养成评价、配装与伤害、导入与备份并列；不保留中间仓库分类或重复二级切换栏。
6. 库存页移除左侧角色列表。圣遗物默认不选参考角色，可主动选择已有角色查看词条权重评价、有效筛选及排序，也可取消；参考角色与养成评价独立。武器为纯库存管理，不隐式限制角色类型。
7. 圣遗物套装筛选使用可搜索、按登场大版本筛选、带图片及分页的选择浮层；其他筛选、折叠与锁定可用性保留。角色圣遗物卡片缩小控件间距，强化与主词条同行。

四、百科材料栏目精简
1. 三个游戏移除材料独立导航、材料养成计算器及详情中的计算器入口；原神养成与评估继续保留。
2. 角色详情在获取途径之前按用途展示养成材料图标和名称，不显示用量，同组重复合并，旅行者天赋材料随元素切换。
3. 同系列按已收录逐阶合成关系相邻展示，高阶在前，各系列优先展示较高稀有度材料。
4. 材料获取途径、用途详情、原始材料资料、个人库存、旧计划和备份保留，统一备份仍可保存这些个人资料。

五、历史卡池与UP统计
1. 按同版本、同起止时刻、时区和安排分组，角色池与武器池并排，突出五星/S级条目；同类型完全相同低星UP名单才合并，不同时间、自选和常驻池独立保留。
2. 集录、溯光等混合池的高稀有度角色和武器分行。整组分页支持每行自动/1/2组；纯角色或纯武器结果宽屏默认两组，混合结果默认一组，手动偏好分别记忆。
3. 卡池安排按上半、下半等顺序，上半紧随全部。UP条目筛选精简为角色稀有度/元素属性/类型及武器稀有度/类型/副属性，保留卡池范围筛选及原统计口径。
4. 卡池详情移除标题占位图、类别和未标注标签，基础资料只展示卡池类型；正式时间与来源资料不改写。

六、版本档案与时装立绘
1. 三游戏版本详情使用顶部标签，更新安排与新增角色装备合并为版本概览，卡池安排及其他有内容主题分别成栏。
2. 移除详情折叠、右侧重复目录、更新日依据说明和底部重复入口；原栏目锚点、关联条目、数值、来源快照及每行数量设置保留，回坑补课汇总折叠保持。
3. 版本内卡池安排共用历史卡池分组与列数布局。
4. 时装与外观直接显示已有本地皮肤立绘，多形态并排标注、按比例完整展示；无对应素材保留文字，原图和时装资料不修改。

七、安装与个人数据
关闭对应目录所有Wiki页面，等待约15秒，并关闭扫描器。将本更新包解压到独立目录，双击“安装更新.vbs”，选择现有1.1.0 / R000004目录，核对版本后开始，以明确显示“更新完成”为准。不要手动覆盖payload、SQLite或其他批次目录。
更新保留收藏、材料库存、旧计划、评估账号、角色装备、队伍与个人扫描；百科条目按三方合并，冲突保留本地值并记录。通用攻略和评价默认方案属于公共设置，若自行修改过，先导出统一备份。
本版按fix修订发布，功能回退仍沿用现有维护者快照；分享版不增加软件版本回退。本轮不检查本机回退，不进行浏览器页面回归或真实游戏扫描；历史界面变更的页面实测状态沿用原记录。
更新后的入口与完整步骤见“Wiki使用说明.txt”。
