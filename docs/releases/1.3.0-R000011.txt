Wiki 1.3.0 版本更新详情
发布批次：R000011
发布日期：2026-10-23

新增功能
1. 新增“关键日期”：集中查看未来一年的版本更新、前瞻直播和下半开启，支持独立游戏筛选、倒计时、月历、推算设置及日历导出；预计节点与已公布节点明确区分。
2. 新增“机制与术语”：共用已有技能、命座／星魂／影画、装备效果和解释资料，按主题与关联角色分组，支持元素／属性、角色及名称筛选。
3. 全文搜索覆盖上述资料，可直接定位并展开目标内容。
4. 跨页面编辑增加修订通知、草稿保留及逐字段冲突处理；仍由用户明确保存，账号锁定与实际装备保护规则保留。

界面与维护改进
1. 更新首页头图，改善首次打开布局，避免首页加载前短暂显示图鉴导航。
2. 调整图鉴、版本档案、关键日期、术语与养成工具的共用控件、标题、菜单及布局；取消全局紧凑模式切换，保留筛选、列数与折叠偏好。
3. 立绘展示按实装版本倒序，同版本再按实装日期和名称排序；角色列表的元素／属性图标移到对应文字旁。
4. 改进初始化批次核对及公共资源缓存，个人账号、收藏、计划、备份和会话接口继续禁止缓存。
5. 统一图片来源与采用优先级，保留修正版；资料与备份聚焦备份、恢复和资料来源，移除普通使用者不需要的维护信息。

游戏资料更新
1. 相对1.2.3 / R000010新增14条、修改89条，共2381条公共条目。
2. 新增原神、星穹铁道、绝区零共9条卡池记录。
3. 新增绝区零角色赛维里安、菲欧妮及音擎烛光诡计、禁罪囚笼、涅槃初翎，补充相关技能、数值、养成及材料资料。
4. 更新绝区零角色头像与修正登记、首页图片、关键日期资料及相关来源快照；原图与历史来源保留。
5. 完整包和软件更新包已包含本次资料；独立资料包另在GitHub“游戏资料更新”发布，不改变软件版本。

安装方法
首次使用：完整解压Windows x64完整包，双击Wiki目录内“启动百科.vbs”；内含运行环境、中文库存扫描器与“Wiki使用说明.txt”。
已安装1.2.1 / R000007、1.2.2 / R000008或R000009、1.2.3 / R000010：使用累计更新包，可直接升级至1.3.0 / R000011。
关闭全部Wiki页面并等待约15秒，关闭扫描器，将更新包解压到独立目录，双击“安装更新.vbs”，选择原Wiki目录或启动文件，确认后等待向导显示“更新完成”。不要把payload或数据库直接覆盖进原目录。
更新保留收藏、库存、养成账号与本地百科编辑；资料冲突保留本地值并记录。早于支持基准或运行时不兼容时，请使用完整包，并通过备份迁移个人资料。
含关键日期数据的本批次资料包，Wiki内自动安装需1.3.0起已列入兼容清单的软件批次；旧版可先升级软件，或使用资料包内新版手动安装器。
