Wiki 1.1.0 版本更新详情
发布批次：R000004
适用更新起点：Wiki 1.0.2 / R000003
发布日期：2026-10-11

本次新增圣遗物配装计算，并加入统一备份与恢复、资料核查及中文扫描器，因此按功能版本发布1.1.0。此前暂记为1.0.3开发范围的修改一并纳入本批次。
更新包和1.1.0完整分享包从同一发布快照生成。更新包包含1.0.2正式发布以来发布范围内全部有效变化；完整包供首次使用或新建干净目录，不含发布者个人数据。

一、新增“圣遗物配装计算”
入口：原神 → 养成与评估 → 配装与伤害 → 圣遗物配装计算，与队伍与伤害、圣遗物、武器并列。
1. 使用当前账号库存及现有计算核心，固定沿用角色当前武器，只搜索圣遗物。支持当前角色和全队范围；全队成员不能重复占用同一件圣遗物。
2. 可选择含当前角色的已保存队伍条件或默认单人队。计算目标独立于搜索角色，可选队员词条评价、面板、伤害、治疗，或全队固定动作合计。
3. 各队员独立配置四件套、2+2、自由第五件、主词条，以及战斗和非战斗面板上下限；两类面板可同时满足或满足任一。支持借用、自定义、锁定装备筛选与试算上限。
4. 角色、套装和计算目标使用搜索浮层，角色与圣遗物按首次登场由新到旧排列，套装可按已收录登场大版本筛选。套装旁提示优先选择适配套装以缩小搜索范围。
5. 后台计算显示进度、前五候选和最好值，支持取消。搜索内复用评分、排序、套装准备及重复求值，仅为最终方案生成完整详情；每次重新计算读取当前库存和条件。
6. 已审定的圣遗物自动准备规则仅应用于搜索和对比副本，不回写角色、武器及已保存队伍条件。原搜索与独立套装分支在同条件下复算、去重取优，各轮使用所选试算上限。
7. 结果显示实际库存原件与归属、完整面板、伤害和五部位圣遗物分析。可查看队伍伤害对比、保存方案；应用实际装备仍须明确操作及权限校验。
8. 按账号、角色、队伍、范围和目标保留结果。装备、条件、筛选或权重变化后旧结果保持只读，重新计算后才能载入、保存或应用。
9. 这是有限候选搜索，不保证全库存最优，不模拟完整循环DPS、附着时序或能量循环；自动规则只覆盖已定义效果。缺少部位或条件无解时给出原因。

二、统一备份、差异预览恢复与资料核查
1. “资料与备份”集中备份百科编辑、收藏、库存、计划、评估账号、导入和扫描存档、队伍方案及通用攻略评价设置；默认.json.gz，可选包含素材的ZIP。
2. 恢复前预览差异、选择范围，账号默认导入副本；替换现有内容须明确确认。素材只补缺失文件，保留现有文件；执行前保存恢复点，业务恢复失败时回滚。
3. 保持旧百科与账号备份的导入能力。个人统一备份含个人数据，分享与更新包仍排除这些数据。
4. 资料核查按需检查关联、图片、待核查字段和已记录来源冲突，区分百科、计算核心与扫描器覆盖，不自动推测或改写正式资料；兼容UTF-8 BOM，格式错误指出具体文件。

三、中文扫描器
1. 分享版改为仅提供Inventory Kamera 1.4.5中文界面，根目录使用“原神库存扫描器（中文）.vbs”；维护者本机原英文入口和程序保留。
2. 中文扫描器按当前目录启动；状态、操作按钮与数量紧凑排列。扫描与识别结果、日志分开；窄窗口选项进入扫描设置页，低窗口支持滚动。
3. 启动仅读取本地识别资料，不自动联网。页面提供手动识别资料更新与扫描器版本检查，后台显示阶段、下载量、耗时及结果，支持取消和超时提示；失败或取消保留原资料。
4. 识别资料更新不覆盖中文界面；更换扫描器程序后才需要重新应用汉化。中文界面不增加中文游戏识别，扫描仍需遵守语言、分辨率、键位与HDR要求。
5. 扫描、游戏导航与GOOD导出逻辑保留。本次发布不进行真实游戏扫描，兼容性以个人试扫与导入预览为准。

四、其他养成与界面改进
1. 评价概览增加圣遗物总双暴值，与已有统计并列；只计圣遗物副词条及理之冠双暴主词条，按暴击率×2＋暴击伤害合计。
2. “我的角色”可按总等效、加权有效词条、圣遗物总双暴排序，支持按账号保存自定义顺序；锁定账号可用，不改角色装备数据。
3. 移除库存装备、自定义圣遗物及队伍后提供30秒撤销，沿用权限和变更冲突保护。
4. 结果对比统一展示正负变化与“不变”，装备移交说明放在对应配装卡片下方；单人和全队展示范围保持一致。
5. 摘要计数、按游戏加载和未变化初始化跳过优化；修正养成计算器导航加载检查及客户端模块依赖名单。
6. 兼容具有明确元素含义的旧风套、勇者套及万叶扩散开关值，不补设缺失层数或改变原公式。

五、包体使用与资料保留
更新包：关闭全部Wiki页面并等待约15秒，同时关闭扫描器；把更新包完整解压到独立目录，双击“安装更新.vbs”，选择原1.0.2 / R000003目录，检查通过后开始更新。以窗口显示“更新完成”为准，不手动覆盖payload或数据库。
完整包：解压到新目录，进入Wiki文件夹双击“启动百科.vbs”。包内自带Node.js与许可文件，不需要安装Node、Git或npm依赖。不要把完整包解压覆盖已有个人使用目录；迁移资料使用统一备份预览恢复。

更新保留个人收藏、材料库存、计划、评估账号、装备、目标、队伍与扫描文件；百科公共条目三方合并，同字段冲突保留本地值并记录。通用攻略和评价默认方案属于公共配置，用户自行修改过时先导出统一备份，可单独恢复；已保存账号目标不自动覆盖。
旧英文扫描器的发布文件从朋友的受管理目录移除，换为中文入口；个人扫描导出与日志保留。维护者本机英文扫描器不删除。
分享版不含软件版本回退工具或功能版本备份。本机发布管理保留上次功能版本的快照引用；本次不检查本机回退。

更新文件、删除项与公共条目变化数量见更新包“更新说明.txt”；新功能步骤、扫描器页面翻译及注意事项见“Wiki使用说明.txt”。两个包使用同一目标1.1.0 / R000004；已经是该批次无需再次安装本更新包。
