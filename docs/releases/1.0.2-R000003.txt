Wiki 1.0.2 版本更新详情
发布批次：R000003
适用起点：Wiki 1.0.1 / R000002
发布日期：2026-10-08

本包汇总1.0.1正式发布以来的有效变化，仅覆盖变化公共文件并按条目合并百科资料。
1.0.1的原安装器、窗口安装器及文件夹选择修正版均属于R000002，成功安装后都可使用本包。

一、角色与装备选择
1. “选择角色”“添加角色”浮层直接展示稀有度、元素按钮及数量，支持多选、联合筛选、各项“全部”和名称搜索。
2. 养成评价的角色列表把来源与元素筛选保持在原同一行，与名称搜索联合生效；旅行者按当前元素合并显示，锁定账号仍可筛选。
3. 攻略武器、套装、角色，以及角色配装中的武器和套装使用可搜索、筛选的选择浮层。浮层筛选直接显示可选按钮。
4. 库存添加自定义武器与圣遗物使用浮层编辑，取消时丢弃未保存草稿。

二、输入与数值筛选修复
1. 圣遗物库存及队伍装备选择窗口的副词条数值筛选仅刷新结果、数量与分页，保留输入节点、光标和输入位置。
2. 清空数值筛选恢复为不限，不把空值自动改成0。
3. 养成评价中的圣遗物、评价目标、词条权重和说明输入时只更新结果及必要联动字段，避免数字输入或光标被整块重绘打断。

三、机制说明与配装对比
1. 在原有按角色分组、并列开关卡片中补全有开关的效果说明和相关数值；长说明在对应卡片内折叠。
2. 不额外铺开全部技能、常驻加成或没有开关的独立效果；未生效空字段不显示成0。
3. 补译依据固定计算源码和已有中文原文，元素开关使用对应枚举值；保留原有公式及实际账号装备。
4. 配装切换后的条件检查提醒与“比较基准 → 当前试算”标题同行，窄窗口自动换行；恢复账号装备后仍提醒核对条件。

四、提升收益计算
1. 比较项目只列当前评价角色的项目。
2. 可以选择单人计算，或选择“队伍与伤害”中包含该角色的已保存队伍，继承该队伍的敌人、机制、反应、额外增益和动作等计算条件。
3. 展示指定项目提升前后期望值、增加量和幅度；选择收益计算队伍不会切换工作台当前队伍，也不会修改实际装备。

五、攻略配队与多套圣遗物方案
1. 配队每个位置单选一名角色，名称和头像统一使用所选角色资料，取消手填职责与名字。
2. 原各位置的多个备选按组合拆成独立完整队伍，保留队伍说明。内置攻略、自定义通用攻略及旧设置导入使用相同兼容规则，原来源快照保留。
3. 一份攻略支持多套独立圣遗物方案，各自设置四件套或2+2及沙、杯、冠主词条，支持单独保存、移除、展示与隐藏。
4. 单套保存只提交该套修改，不提交其他未保存草稿；旧单套配置兼容为第一套。
5. “圣遗物建议”统一提供可编辑文本及独立保存，原默认建议保留；通用攻略编辑仍不受账号锁定影响。

六、窗口式更新器与教程
1. 本包自带窗口式向导：双击“安装更新.vbs”，或使用“安装更新.cmd”打开同一窗口。
2. 支持选择原Wiki文件夹或直接选择“启动百科.vbs”；外层目录只有一份Wiki时自动定位。
3. 显示当前与目标版本、目录检查、实际阶段进度，以及完成、失败或已更新结果；结果窗口保留，可启动Wiki、打开目录或查看日志。
4. “选择文件夹”已修正初始路径为空或只有空白时的错误。使用教程同步补充本次新功能。

七、安装与资料保留
1. 关闭所有Wiki页面并等待约15秒，同时关闭扫描器。完整解压本更新包到独立目录，不直接解压覆盖原Wiki。
2. 在向导中选择现有1.0.1 / R000002目录，检查通过后点击“开始更新”，以窗口明确显示“更新完成”为准。
3. 保留个人收藏、材料库存、养成计划、评估账号、实际及自定义装备、队伍与原始扫描；不替换个人数据库。
4. 百科公共资料按条目合并，双方修改同一字段时保留本地值并输出冲突记录。
5. 通用攻略与评价默认方案属于公共配置，会随本包更新。自行编辑过的接收者可在安装前另存 modules\character-assessment\core\recommendation-overrides.json；已保存账号目标不会被自动覆盖。
6. 分享版不含本机版本回退工具。已经是R000003无需重复安装；1.0.0或其他批次不能使用本包，应索取对应起点更新包。

实际文件、删除项及百科变化数量见“更新说明.txt”；完整使用教程见“Wiki使用说明.txt”。
